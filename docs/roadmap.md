# 已知限制与路线图

下列功能是建议方向，不是已经实现的功能，也不承诺发布日期。

| 优先级 | 方向 | 验收重点 |
| --- | --- | --- |
| P1 | 定时备份、轮换和恢复检查 | 断电后可恢复；失败可见；不覆盖唯一副本 |
| P2 | 章序调整 | 记忆、事件、卷归属和来源顺序同步更新 |
| P2 | 全书查找替换 | 预览范围、撤销及版本快照 |
| P2 | DOCX 输出、整书拆章导入 | 章名、排序、编码与超长内容保持 |
| P2 | 人物别名与失效记忆复核/重建 | 不把猜测和未来情节写成事实 |
| P2 | 模型用量与失败管理 | 请求透明、可取消、重试不重复采用 |
| P3 | 跨设备同步 | 版本冲突、安全和数据完整性 |

当前不包含上述模块、向量检索、多人协作及 DOCX/PDF 导入导出。英文长度按字符数统计。AI 模型兼容性由实际服务决定，长篇一致性需要作者审核。

Windows x64 为此次打包平台；没有交付 macOS、Linux、ARM64 安装包。未配置代码签名证书。本地测试通过不等于在每台电脑或每种 API 上都通过。
