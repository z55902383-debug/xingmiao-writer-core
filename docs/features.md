# 开源核心版功能

**会员免费，无需付费开通。** 完整版中的会员与普通用户区分，仅用于方便管理广场提示词库、区分相关权限，不是收费套餐。第三方 AI 模型和生图 API 可能由服务商计费，与免费会员无关。开源核心版不包含账号、会员和广场模块。

v0.6.4，2026-10-06。无需星喵账号即可使用。AI 由用户配置自己的兼容接口或本机 Codex，服务商费用另计。

| 模块 | 功能 |
| --- | --- |
| 书架 | 新建、搜索、最近作品、示例、归档、删除与恢复 |
| 编辑 | 自动/手动保存、专注、字号、字数、查找、正文/选区复制、单章 TXT |
| 章节与分卷 | 新建/复制/删除/恢复章节、分卷、大纲与细纲、概要、目标字数、定稿 |
| 历史 | 每章最近 100 个版本快照，查看和恢复 |
| 故事资料 | 人物、世界背景、作者规则、备忘录、伏笔、风格参考与原文记忆 |
| 关系与时间 | 交互图谱、时间线、人物身份/阵营/生存状态、按章回看 |
| 资料画布 | 来源共用、布局保存、标注、连线、常规视图切换 |
| AI | 写作、续写、润色、大纲、资料生成、连续性检查、风格分析与记忆提取 |
| 候选审核 | 预览后采用、来源变更保护、生成后变化分析、证据确认与事务同步 |
| 模型 | 多配置、连接测试、流式输出、手动停止、加密 API 密钥、可选 Codex |
| Skill | 文字指令创建/编辑/启停/任务绑定，SKILL.md 文件/目录导入导出 |
| 输出与恢复 | Markdown 整书、TXT 单章、JSON 备份与副本恢复、回收站 |
| 本地设置 | 数据目录查看/迁移、中文/英文、深浅主题 |

新用户：想法 → 全文大纲 → 分卷 → 卷大纲/细纲 → 章节大纲/细纲 → 正文 → 定稿完成。每步先生成、核对，再采用；名称与内容同步到对应位置。人物/世界可按需要补充。

[完整操作与采用规则](分步创作流程与采用说明.md) · [本次检查记录](检查记录-v0.6.4.md)

本地编辑、管理和备份可离线使用。模型任务会把所需正文和资料发送至用户选择的服务；参考原文用于风格分析。普通 JSON 作品备份不包含 API 密钥、账户信息和所有应用设置。

来源记忆按章节顺序与版本校验；修改旧章后需复核过期资料。画布标注只是作者注释，不自动成为事实。技能不执行代码。不保证 AI 生成无矛盾或无错误。

开源核心版不含完整软件的创意工具箱、生图、飞书账号、会员、共享广场和内置更新服务。
