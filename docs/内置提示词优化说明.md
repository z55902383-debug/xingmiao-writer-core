# 内置提示词优化说明

补充：后续视频文案参考优化已将内置 Skill 增至14项，并增加本次生成独立选择。最新操作及验证范围见[视频文案参考优化说明](视频文案参考优化说明.md)。以下保留此前15份提示词资料的整理记录。

本次参考用户提供的15份大纲、细纲、正文与写法分析资料，整理为适合星喵写作现有流程的原创指令。原始文档作为参考资料读取，没有执行其中的角色指令、系统操作或输出命令。原始文档及提取全文不加入发布源码。

## 已融入生成步骤

| 位置 | 优化内容 |
| --- | --- |
| 全文大纲 | 故事核心、目标与对抗力量、因果推进、人物成长、阶段转折、结局方向与伏笔计划 |
| 分卷与卷大纲 | 阶段目标、冲突升级、选择代价、卷末状态与下一卷承接；保持现有分步生成流程 |
| 卷细纲与章节规划 | 可拆章的具体事件、场景结果、情绪变化、人物关系和伏笔时机；不套固定章数 |
| 章节细纲 | 场景顺序、视角、时间地点、行动对白作用、读者和各角色的知情差、场景转折与承接 |
| 人物与世界 | 动机、弱点、底线、人物声线、能力条件和代价、组织资源与规则自洽；初始背景与未来规划分开 |
| 正文与续写 | 承接实际前文、目标阻碍与行动后果、对白差异、细节作用与内部连续性检查；续写只输出新增内容 |
| 润色 | 保留事件、关系、信息揭露顺序和作者文风；减少重复与机械描写，输出完整修订正文 |
| 风格与要求蒸馏 | 场景功能、情绪和信息节奏、可定位分析依据、适用范围；区分观察特征、推导建议和明确要求 |

所有规划步骤仍采用原有JSON结构，名称和真实编号继续同步到对应卷章。正文仍使用现有排版设置，不附自评分、伏笔说明或分析过程。记忆提取与故事检查保留证据要求，不加入题材创作模板。人工码字的灵感助手仍只讨论思路。

## 可选内置 Skill

在“模型与设置 → 写作 Skill”中查看、编辑和启用。所有新增项默认关闭，只有启用且属于当前任务的内容才会发送。

原有“场景与冲突”“人物连续性”“自然叙事”补充了因果、知情差、人物选择与自然表达方法。另增加七项：玄幻战斗与成长、悬疑灵异与线索、都市先婚后爱、古言语境与人物声线、权谋博弈与反转、种田宅斗与日常张力、仙侠情感与留白。

同一本书建议只启用符合题材的条目，并在“风格与参考”中选择本次需要的写作风格与要求。作者本次补充要求和明确选择的风格优先于一般默认建议；事实边界、任务格式和人物认知边界继续有效。

## 旧资料保护

旧的基础内置条目只有名称、来源、正文、说明、适用任务都与原始默认一致时才会升级。升级保留编号、启用状态并增加版本号。人工修改、手动导入和同名自定义条目保留。此前删除的基础内置不重新创建；这批新增题材条目首次补充后，删除也不会在每次启动时重建。100条上限已满时保留现有资料。

## 没有照搬的规则

参考资料中的固定对白比例、全量常用词禁用、强制第三人称、固定章节节拍、每章一收一埋、必须救美或圆满结局等，不作为所有作品的共同约束。正文示例中的人物、器物与剧情也不复制到用户作品。

“短视频文案”资料面向推广口播，未接入小说正文生成。平台算法、审核和AI检测效果没有可验证依据，未加入保证性承诺。少量章段不能代表未提供的完整作品，蒸馏时要求如实说明资料范围。
